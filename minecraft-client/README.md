# krof-smp client pack (draft)

This private, noncommercial pack uses Fabulously Optimized 15.0.0-beta.4
for Minecraft 26.3 and Fabric Loader 0.20.1, plus stable Xaero minimap, world
map, and Jade releases. The beta base is an explicit exception. Open Parties
and Claims is removed: land, containers and parties have no claim protection.
Entity Culling remains excluded due to unclear private distribution terms.
The server requires Faithful 64x Release 15.

Run `python3 minecraft-client/build.py` to build
`minecraft-client/dist/krof-smp-2.0.0.mrpack`. The builder verifies the base
archive, download hashes and sizes; it references official downloads without
bundling mod binaries. Import as a separate Modrinth App profile, retaining the
prior pack and backing up local waypoints. Never include private addresses.

Launcher import, actual client login and gameplay remain unverified. Recheck
component licenses and base override redistribution before sharing the new pack;
the component record provides metadata but is not approval for redistribution.
